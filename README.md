# 스마트 팩토리 IoT 센서 시계열 데이터 분석 대시보드

본 프로젝트는 폴더 내의 **`센서 스무딩.xlsx`** (24시간 연속, 1분 주기 다변량 센서 데이터)를 정밀 분석하고, **20가지 고급 데이터 분석 및 신호 처리 기법**을 적용하여 인터랙티브하게 시각화 및 진단하는 웹 기반 대시보드입니다.

---

## 🌟 핵심 특징

1. **순수 HTML, CSS, JavaScript (Vanilla Web)**
   - 별도의 번들러, Vite, Webpack, Node.js 빌드 과정 없이 `index.html` 파일을 더블클릭하는 것만으로 Chrome, Edge, Safari, Firefox 등 모든 웹 브라우저에서 즉시 실행됩니다.
2. **100% 로컬 오프라인 실행 및 데이터 외부 전송 Zero**
   - 모든 분석 알고리즘(칼만 필터, 사비츠키-골레이, 푸리에 변환, CUSUM, EWMA 등)이 브라우저의 JavaScript 엔진에서 100% 클라이언트 사이드로 연산됩니다.
   - 외부 서버나 클라우드로 단 1바이트의 데이터도 전송되지 않아 보안이 중요한 산업 플랜트나 에어갭(Air-gapped) 환경에서도 안전하게 사용할 수 있습니다.
   - 차트 라이브러리(`Chart.js`)와 엑셀 파서(`SheetJS`)가 `lib/` 폴더에 로컬 저장되어 있어 인터넷 연결 없이도 완벽하게 작동합니다.
3. **참값(Ground Truth) 기반 정량 벤치마킹**
   - 센서 원시값과 실제 참값(Ground Truth)이 모두 포함된 데이터셋 특성을 활용하여 주관적 시각 평가가 아닌 RMSE, MAE, Max Error, SNR 이득(dB), 노이즈 감쇄율(%) 등 정량 지표를 산출합니다.

```text

├── js/
│   ├── analytics.js        # 20개 분석 기법 순수 자바스크립트 수학 연산 엔진
│   └── dashboard.js        # 대시보드 인터랙션 컨트롤러 및 차트 매니저

│   ├── chart.umd.min.js    # 로컬 Chart.js (v4.4.1)

└── README.md               # 프로젝트 안내 및 분석 해설 요약서
```

## 🔬 적용된 20개 데이터 분석 기법 요약

| 번호 | 기법 명칭 | 분류 | 설명 및 적용 목적 |
|:---:|:---|:---|:---|
| **01** | **단순 이동평균 (SMA)** | 신호 정제 | $W$구간 산술평균으로 백색 노이즈 제거, 윈도우별 위상 지연(Phase Lag) 비교 |
| **02** | **지수 가중 이동평균 (EMA)** | 신호 정제 | 최근 관측치에 지수 가중치 부여, 급격한 부하 변동에 대해 SMA 대비 지연 최소화 |
| **03** | **사비츠키-골레이 필터 (Savitzky–Golay)** | 신호 정제 | 국소 다항식 최소제곱 회귀를 통해 과열 피크의 첨두값과 변곡점 형상을 충실히 보존 |
| **04** | **중앙값 필터 (Median Filter)** | 신호 정제 | 비선형 순위 필터로 센서 전원 노이즈/단일 스파이크를 완벽하게 제거 |
| **05** | **햄펠 필터 (Hampel Filter)** | 신호 정제 | $3 \times 1.4826 \times \text{MAD}$ 초과 이상치만 선별 교체하고 정상 구간은 원형 보존 |
| **06** | **1차원 칼만 필터 (Kalman Filter)** | 신호 정제 | 공정 노이즈($Q$)와 측정 오차($R$)의 베이지안 재귀 갱신을 통한 실시간 최적 추정 |
| **07** | **피크 포락선 분석 (Peak Envelope)** | 신호 정제 | 롤링 최대/최소값으로 설비 운전 변동 대역폭 및 열적 변동 한계 추적 |
| **08** | **필터 오차 정량 벤치마킹** | 성능 평가 | 참값 대비 RMSE, MAE, Max Error, 피어슨 상관도를 계산하여 최적 필터 선정 |
| **09** | **SNR 및 노이즈 감쇄율 분석** | 성능 평가 | 원시 신호 대비 잔차 노이즈 분산 감소율(%) 및 신호 대 잡음비 이득(dB) 산출 |
| **10** | **이동 Z-Score 이상치 탐지** | 이상치 탐지 | 롤링 윈도우 동적 평균·표준편차 기반 $\pm 3\sigma$ 초과 이상 계측 검출 |
| **11** | **IQR 사분위수 기반 판별** | 이상치 탐지 | 비모수적 $Q_1 - 1.5\text{IQR} \sim Q_3 + 1.5\text{IQR}$ 정상 운전 대역 경계 설정 |
| **12** | **SPC EWMA 관리도** | 공정 관리 | 통계적 공정 관리 한계선($\mu \pm 3\sigma$)을 통한 설비 미세 표류(Drift) 조기 경보 |
| **13** | **누적합 관리도 (CUSUM)** | 공정 관리 | 잔차 편차 누적($C^+, C^-$)을 통해 과열/부하 증가의 최초 시작 시점을 포착 |
| **14** | **알고리즘 탐지 성능 벤치마크** | 정량 평가 | 정답 이벤트 대비 Precision, Recall, F1-Score, Confusion Matrix 정량 산출 |
| **15** | **다변량 상관계수 행렬** | 설비 동역학 | 온도, 진동 RMS, 압력 간 피어슨(선형) 및 스피어만(순위) 결합 강도 분석 |
| **16** | **상호상관 시차 분석 (Lag Analysis)** | 설비 동역학 | $R_{xy}(\tau)$를 통해 압력(3분 전 선행)과 진동이 온도를 선행하는 리드타임 규명 |
| **17** | **60분 롤링 동적 상관도** | 설비 동역학 | 정상 운전 vs 부하 급증 상태에서의 변수 간 결합도 변화를 시계열로 추적 |
| **18** | **위상 공간 (Phase Space) 상태 궤적** | 설비 동역학 | 표준화 2D 위상 공간(진동-온도)에서 운전 상태별 클러스터링 및 이상 궤적 분석 |
| **19** | **이산 푸리에 변환 (DFT / PSD)** | 주파수 분석 | 전력 스펙트럼 밀도 분석을 통해 24시간 일주기 및 4시간 공정 주기 성분 검출 |
| **20** | **자기상관함수 (ACF) 분석** | 주기성 분석 | 시차 0~180분 구간 자기상관 감쇄 곡선으로 신호 메모리 및 주기성 지속성 평가 |

## 💡 데이터 분석 결과 핵심 해설

1. **센서 스파이크(결함)와 실제 과열(물리 이상)의 완벽한 분별**
   - **스파이크 이상치 (7건)**: 188분, 412~413분, 777분, 1012분, 1188분, 1325분에서 온도가 1분 만에 7~9°C 급락 또는 급등하지만, **진동 RMS와 압력은 완전히 정상 수준을 유지**합니다. 이는 금속 설비의 열역학적 열용량상 불가능한 변화로, 센서 하드웨어/접촉 노이즈입니다.
   - **급격한 과열 (784~796분)**: 온도가 36.0°C까지 상승할 때 **진동 RMS는 2.56 mm/s(+76%)**, **압력은 103.90 kPa(+2.1 kPa)** 동반 급증합니다. 3개 센서가 동시에 치솟으므로 이는 실제 기계적 과부하에 의한 위험 징후입니다.
2. **다변량 선행 지표 (압력의 3분 선행 발견)**
   - 상호상관 분석 결과, **압력은 온도 상승을 약 3분 선행**($\tau = -3$)하여 최고 상관도를 기록합니다. 압력 서지 발생 후 배관 및 금속체로 열이 전도되는 열용량 지연(Thermal Lag)이 존재함을 실증하며, 이를 활용해 과열 3분 전에 사전 경보를 발령할 수 있습니다.
3. **최적 필터 추천**
   - 전체 RMSE 최소화 및 과열 피크 진폭 보존 측면에서 **Savitzky-Golay (윈도우 15, 2차 다항식)** 및 **햄펠 필터(윈도우 7)**가 가장 우수한 성능을 나타냈습니다.
   - 엣지/PLC 실시간 파이프라인에는 메모리 소모가 적은 **1차원 칼만 필터($Q=0.02, R=0.8$)**가 가장 권장됩니다.
